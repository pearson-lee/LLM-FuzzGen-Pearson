# Triage Archive

This directory contains triage development artifacts that are retained for auditability but must not be treated as the final three-run result.

- `initial/`: original prompt and decision outputs before label-only routing and evidence-contract refinement.
- `label_routing/`: intermediate label-only deterministic-routing run.
- `incomplete/`: interrupted evidence-contract run containing only 3 of 9 cases.
- `notes/`: historical implementation and prompt-refinement notes.

The reviewed complete runs are in `TODO_MD/triage_final/`.
